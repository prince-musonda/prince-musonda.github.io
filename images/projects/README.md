# Project images

Place project screenshots or preview images in this folder. Use descriptive filenames such as `icare-ai.webp`, `gpt-style-slm.webp`, or `lulu.webp`, then replace the corresponding image placeholder in `index.html` with an `<img>` using a path like `images/projects/icare-ai.webp`.

Recommended format: WebP or JPEG, landscape 16:9, optimized for the web.
